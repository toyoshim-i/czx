# Commodore 64 (`vice_x64sc` / `vice_x64`)

`czx` bundles two VICE C64 libretro cores built with `-USE_EMBEDDED` (external ROM loading only):
- **`vice_x64sc`**: cycle-exact MOS 6569/6581 emulation (highest accuracy).
- **`vice_x64`**: lighter C64 core with `FastSID` enabled by default for lower CPU load on Cardputer Zero.

## ROM Setup

Place the following VICE system ROMs using **exact lowercase filenames** under `~/czx/roms/vice/`:

| Path (relative to `~/czx/roms/vice/`) | Size | Status | Purpose |
| :--- | :--- | :--- | :--- |
| `C64/kernal-901227-03.bin` | 8 KiB | **Required** | C64 KERNAL ROM (rev. 3) |
| `C64/basic-901226-01.bin` | 8 KiB | **Required** | C64 BASIC V2 ROM |
| `C64/chargen-901225-01.bin` | 4 KiB | **Required** | C64 character generator ROM |
| `DRIVES/dos1541ii-251968-03.bin` | 16 KiB | **Required** | 1541-II floppy drive DOS ROM |
| `DRIVES/dos1541-325302-01+901229-05.bin`, `dos1571-*`, `dos1581-*`, JiffyDOS ROMs | Varies | Optional | Extra drive models / fast DOS ROMs |

If any of the four required ROMs are missing, `czx` displays a **ROM FILES REQUIRED** prompt naming `~/czx/roms/vice/` and the missing files.

## Media Setup & Usage

- Put C64 disk, tape, cartridge, or `.prg` files in `~/czx/media/c64/`.
- Open `Alt + 8` → **Load Media** to select a file (`PRG`/`D64`/`CRT` autostart).
- **Floppy hot-swap**: Switching from one disk image (e.g., `.d64`/`.g64`) to another uses VICE's disk control interface when supported.
- **Tape (`.tap`) playback**: After loading a `.tap` file (and typing `LOAD` if prompted), open `Alt + 8` → **Tape Play** (`[Enter]`) to pulse Datasette START (`RETROK_KP_PLUS`).

## Display & Controls

- **Borders (`Alt + 8` → Borders)**: `czx` crops PAL (`384×272`) and NTSC (`384×247`) frames to the `320×200` active area by default; toggle **Borders** to view the full border frame.
- **Joystick Port 2 default**: Most C64 games read **Port 2**, and `czx` configures `vice_joyport = 2` by default so `Alt + 7` → **Joy P1** controls Port 2 automatically (`F/Z/X/C` move, `Space` = Fire).

## Configuration & Save Data

Per-core config files: `~/czx/config/vice_x64sc.cfg` and `~/czx/config/vice_x64.cfg`.
Defaults seeded by `czx`:

```ini
# Also "FastSID" automatically on vice_x64:
# vice_sid_engine = FastSID
vice_resid_sampling = fast
vice_drive_true_emulation = enabled
vice_zoom_mode = none
vice_c64_model = C64 PAL auto
vice_joyport = 2
vice_autoloadwarp = enabled
vice_datasette_hotkeys = enabled
vice_mapper_datasette_start = RETROK_KP_PLUS
vice_mapper_datasette_stop = RETROK_KP_MINUS
```

- **Save Data**: VICE stores configuration in `~/czx/saves/vicerc`.
