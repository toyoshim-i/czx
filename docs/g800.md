# SHARP PC-G850 / PC-G815 / PC-E200 (`g800`)

`czx` includes a built-in native port of `g800` v0.11.4 (2-Clause BSD, no external `.so` file) with compatible BASIC, IOCS, and machine-language monitor out of the box, plus optional real SHARP pocket computer ROM loading.

← [Back to README](../README.md)

## Quick Facts

| Item | Value |
| :--- | :--- |
| Core ID | `g800` (built-in) |
| Model Presets (`--preset`) | `0`: `PC-G850 (144×48)` *(default)*, `1`: `PC-G815 (144×32)`, `2`: `PC-E200 (120×32)` |
| ROM Directory | `~/czx/roms/g800/` (or per-model `g850/`, `g815/`, `e200/` subdirs) |
| ROM Case Sensitivity | **Case-sensitive (lowercase filenames required on Linux)** |
| External ROMs Required? | **Optional** (built-in compatible BASIC / IOCS / monitor) |
| Media Directory | `~/czx/media/g800/` |
| Supported Media | `.ihx`, `.hex`, `.bas`, `.txt` |
| LCD Rendering | Crisp `2×` dot-matrix pixel grid with LCD status indicators inside `320×170` |

## ROM Setup

Without external ROMs, `g800` boots straight into its built-in compatible BASIC / IOCS / monitor environment.

To run real SHARP ROM dumps, place `base.bin` (or `base.txt`) and `rom00.bin` (or `rom00.txt`), `rom01.*`, etc. using **exact lowercase filenames**:
- **Per-model directories (checked first)**:
  - `~/czx/roms/g800/g850/`
  - `~/czx/roms/g800/g815/`
  - `~/czx/roms/g800/e200/`
  If `base.bin` or `base.txt` exists in the active preset's subdirectory, `czx` loads ROMs from that subdirectory.
- **Shared fallback directory**: `~/czx/roms/g800/`.

## Switching Models

Launch a specific model preset from the command line:

```bash
czx --core g800 --preset 0   # PC-G850 (144x48)
czx --core g800 --preset 1   # PC-G815 (144x32)
czx --core g800 --preset 2   # PC-E200 (120x32)
```

## Media Setup & Usage

- Put Intel HEX and BASIC text programs in `~/czx/media/g800/`.
- Open `Alt + 8` → **Load Media** (or pass `--media <file>`):
  - **In built-in compat mode**:
    - `.ihx` / `.hex`: loads Intel HEX bytes directly into RAM and persists RAM.
    - `.bas` / `.txt`: imports the BASIC listing and automatically triggers `CLOAD` if currently in BASIC mode.
  - **With real SHARP ROMs**: loads the file via simulated SIO input.

## Special Keys & Controls

| Host / Cardputer Key | Pocket Computer Key | Host / Cardputer Key | Pocket Computer Key |
| :--- | :--- | :--- | :--- |
| `F1` | `BASIC` | `F6` | `KANA` |
| `F2` | `TEXT` | `F7` | `CONST` |
| `F3` | `2ndF` | `F8` | `ANS` |
| `F4` / `Home` | `CLS` | `F9` / `Shift + ESC` | `OFF` |
| `F5` | `CAPS` | `F10` | `MENU` |
| `ESC` | `ON / BRK` | `BS` / `DEL` | `BS` |
| `INS` | `INS` | `\'` / `"` (`APOSTROPHE`) | `*` (`ASTER`) |

- **Joystick P1 (`Alt + 7`)**: `F/Z/X/C` map to cursor Up/Down/Left/Right, `Space` = `Space`, `Enter` = `Return`.
