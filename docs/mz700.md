# SHARP MZ-700 (`emuz700`)

`czx` runs SHARP MZ-700 emulation via Takeda Toshiya's Common Source Code Project (`EmuZ-700`, GPLv2, compiled standalone as `emuz700_libretro.so`) strictly with external ROM loading.

## ROM Setup

Place your legal MZ-700 ROM dumps in `~/czx/roms/mz700/` (matched case-insensitively):

| Primary Name | Accepted Aliases (case-insensitive) | Size | Status | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `IPL.ROM` | `1Z-009A.ROM`, `1Z-009B.ROM`, `1Z009A.ROM`, `1Z009B.ROM`, `MZ700IPL.ROM`, `NEWMON7.ROM` | 4 KiB | **Required** | MZ-700 Monitor / IPL ROM (`0x0000–0x0FFF`) |
| `FONT.ROM` | `MZ700FON.JP`, `MZ700FON.DAT`, `MZ700FON.ROM`, `CGROM.ROM`, `MZ700FONT.ROM` | 4 KiB | **Required** | Character generator CGROM |
| `MZ1R12.ROM` | — | 2 KiB | Optional | CMOS SRAM unit expansion ROM (requires DIP switch) |
| `MZ1E14.ROM` | — | 2 KiB | Optional | Quick Disk controller I/F ROM (requires DIP switch) |
| `MZ1E05.ROM` | — | 4 KiB | Optional | Floppy disk controller I/F ROM (requires DIP switch) |
| `EMM.ROM` | — | Varies | Optional | Expansion memory module ROM |
| `KANJI.ROM`, `DICT.ROM` | `MZ1R23.ROM`, `MZ1R24.ROM` | Varies | Optional | Kanji & dictionary expansion ROMs |

If either the IPL ROM or FONT ROM is missing, `czx` displays a **ROM FILES REQUIRED** screen listing `~/czx/roms/mz700/` and the missing ROM aliases.

## Media Setup & Usage

- Put tape, Quick Disk, and floppy files in `~/czx/media/mz700/`.
- **Loading a tape (`.mzt`, `.mzf`, `.m12`, `.wav`, `.cas`, `.tap`, `.t77`)**:
  1. Open `Alt + 8` → **Load Media** and choose your tape image (`emuz700` mounts and cues the tape).
  2. At the MZ-700 monitor prompt (`*`), type `L` + `Enter` — the MZ-700 data recorder remote automatically starts playback, and **Tape Warp** (`Alt + 8 → Tape Warp: On` by default, persisted in `~/czx/config/czx.cfg` as `tape_warp = on|off`, or `--tape-warp on|off`) runs emulation at uncapped host speed in exact cycle lockstep until loading finishes (requires `emuz700_tape_sound = disabled`). Reset keeps the mounted tape cued.
  3. To manually toggle tape PLAY/STOP at any time (with automatic rewind at end-of-tape), use `Alt + 8` → **Tape Play**.
- **Quick Disk (`.q20`) & Floppy (`.d88`, `.2d`)**: Selecting a `.q20` mounts Quick Disk 0; `.d88` / `.2d` mounts Floppy Drive 0.

## Controls & Special Keys

| Host / Cardputer Key | MZ-700 Key | Host / Cardputer Key | MZ-700 Key |
| :--- | :--- | :--- | :--- |
| `ESC` | `BREAK` | `F6` / `PgUp` | `KANA` |
| `BS` / `DEL` | `DEL` | `F7` / `PgDn` | `EISUU` |
| `INS` | `INST` | `F8` / `LAlt` | `GRAPH` |
| `F1`–`F5` | `F1`–`F5` | `Enter` | `CR` |

- **Joystick P1 / P2 (`Alt + 7`)**: `F/Z/X/C` = Directions, `Space` = Button A (`FIRE1`), `Enter` = Button B (`FIRE2`).

## Configuration (`~/czx/config/emuz700.cfg`) & Save Data

Defaults seeded by `czx`:

```ini
emuz700_joystick = JOY-700     # JOY-700 | AM7J | MZ-1X03
emuz700_tape_sound = disabled  # disabled | enabled
emuz700_tape_turbo = enabled   # enabled | disabled
```

- **Save Data**: Writable CMOS RAM (`CMOS.BIN`) and Quick Disk temp files are stored separately under `~/czx/saves/mz700/` so `~/czx/roms/mz700/` remains read-only.
