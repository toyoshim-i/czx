# NEC PC-8801 (`quasi88`)

`czx` runs PC-8801mkIISR emulation via `QUASI88` (`quasi88_libretro.so`, OPNA sound, `N88 V2` default). A clean-room pseudo BIOS fallback is built in, while real NEC PC-88 ROMs unlock full commercial software compatibility and Japanese fonts.

## ROM Setup

`quasi88` boots even when `~/czx/roms/quasi88/` is empty, using its built-in pseudo BIOS (and falls back cleanly for missing font ROMs). For commercial games, disk BASIC (`N88 V2` / `V1H` / `V1S` / `N-BASIC`), and full Japanese text in both guest software and the `F12` menu, place your NEC PC-88 ROMs in `~/czx/roms/quasi88/`:

| Preferred Filename | Accepted Aliases (UPPER / lower) | Status | Purpose |
| :--- | :--- | :--- | :--- |
| `N88.ROM` | `n88.rom` | Recommended | N88-BASIC V2 main ROM (32 KiB) |
| `N88_0.ROM`..`N88_3.ROM` | `N88EXT0.ROM`..`N88EXT3.ROM` | Recommended | 4th ROM banks (8 KiB each) |
| `N88N.ROM` | `N80.ROM`, `n88n.rom`, `n80.rom` | Optional | N-BASIC (PC-8001 compatibility) ROM |
| `DISK.ROM` | `N88SUB.ROM`, `disk.rom`, `n88sub.rom` | Recommended | Intelligent FDC sub-CPU ROM (2 KiB) |
| `FONT.ROM` | `font.rom` | Recommended | 8×8 ANK / kana / semi-graphic font |
| `KANJI1.ROM` | `N88KNJ1.ROM`, `kanji1.rom`, `n88knj1.rom` | Recommended | JIS Level 1 Kanji ROM (128 KiB) |
| `KANJI2.ROM` | `N88KNJ2.ROM`, `kanji2.rom`, `n88knj2.rom` | Optional | JIS Level 2 Kanji ROM (128 KiB) |
| `JISYO.ROM` | `N88JISHO.ROM`, `jisyo.rom`, `n88jisho.rom` | Optional | Dictionary ROM |

## Media Setup & Usage

- Put `.d88`, `.t88`, `.cmt`, or `.m3u` files in `~/czx/media/pc88/`.
- **Dual Floppy Drives**: Open `Alt + 8` and use **Drive 1** / **Drive 2** (`OK`/`Enter` to browse/insert, `Z` to eject).
- **Multi-disk `.d88` images**:
  - Selecting a multi-disk `.d88` archive in `czx`'s file browser displays all embedded disks plus `[AUTO] D1:#1 + D2:#2`, which mounts the first two disks into Drive 1 and Drive 2 together.
  - Launching with `--media multi_disk.d88` on the CLI also auto-mounts sub-disks #1 and #2 into Drive 1 and Drive 2.
  - When both drives are occupied, `czx` writes a temporary boot playlist to `~/czx/saves/czx_quasi88.m3u`.
- Tape files (`.t88`, `.cmt`) and `.m3u`/`.zip` files load directly into the single media slot (ejecting Drive 2).

## Controls & Special Keys

- **`F12`**: Opens or closes QUASI88's built-in configuration menu.
- **Joystick P1 (`Alt + 7`)**: `F/Z/X/C` = Directions, `Space` = Button A (`FIRE1`), `Enter` = Button B (`FIRE2`).

## Configuration (`~/czx/config/quasi88.cfg`)

Optional overrides read on startup (`czx` seeds these defaults automatically):

```ini
q88_basic_mode = N88 V2
q88_sub_cpu_mode = 2
q88_cpu_clock = 4
q88_sound_board = OPNA
q88_use_fdc_wait = enabled
q88_rumble = disabled
q88_screen_size = full
```

Other supported options include `q88_pcg-8100` and `q88_save_to_disk_image`.
