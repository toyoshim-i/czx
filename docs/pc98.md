# NEC PC-9801 (`np2kai`)

`czx` runs PC-9801VX emulation via `Neko Project II kai` (`np2kai_libretro.so`, 2.4576 MHz ×4, PC9801-86 sound). A built-in HLE BIOS fallback lets you boot basic software immediately, while real NEC PC-98 ROMs unlock full OS/game compatibility and Japanese fonts.

## ROM Setup

Place your real NEC PC-98 ROMs in `~/czx/roms/np2kai/` using **lowercase filenames**:

| Filename | Status | Purpose |
| :--- | :--- | :--- |
| `bios.rom` | Recommended | PC-98 system BIOS ROM (96 KiB) |
| `itf.rom` | Recommended | Initial Test Function (ITF) ROM (32 KiB) |
| `sound.rom` | Recommended | PC9801-86 / 26K sound BIOS ROM (16 KiB) |
| `font.bmp` (or `font.rom`) | Recommended | PC-98 ANK & Kanji font data |
| `2608_bd.wav`, `2608_sd.wav`, `2608_top.wav`, `2608_hh.wav`, `2608_tom.wav`, `2608_rim.wav` | Optional | OPNA rhythm sound samples (ADPCM/rhythm drums) |

> **Important**: Avoid placing `d8000.rom` in `~/czx/roms/np2kai/` unless you specifically need IDE/SASI HDD BIOS support for a hard drive image — keeping `d8000.rom` present can cause floppy-only boots to hang at startup.

## Media Setup & Usage

- Put floppy and hard disk images in `~/czx/media/pc98/`.
- **Dual FDD (`FDD 1` / `FDD 2`)**: Open `Alt + 8` and select **FDD 1** or **FDD 2** (`OK`/`Enter` to load, `Z` to eject). Hot-swapping floppies works while running via NP2kai's disk control interface.
- **Multi-disk `.d88` images**: Selecting a multi-disk `.d88` in the file browser offers `[AUTO] D1:#1 + D2:#2` as well as individual sub-disk selection.
- **Hard Disks (`.nhd`, `.hdi`, etc.)**: Loading an HDD image attaches it automatically alongside any inserted FDDs (writing `~/czx/saves/czx_np2kai.cmd` and restarting cleanly with both FDDs and HDD mounted). Ejecting **FDD 1** when no floppy is loaded detaches the HDD.

## Display & Controls

- **Recommended display mode**: **Axis Fit** (`Alt + 5`) scales `640×400` into `320×170`, or use **1:1 Pan** (`Alt + 4`) for sharp unscaled 80-column text with `Alt + F / Z / X / C` scrolling.
- **Input Modes (`Alt + 7`)**: Cycles `Keyboard → Joy P1 → Joy P2 → Mouse (FZXC)`. PC-98 mouse input (`np2kai_inputmouse = ON`) is enabled by default (`F/Z/X/C` move cursor, `Space` = Left click, `Enter` = Right click when in Mouse mode).
- **NP2kai Menu**: Pressing `F12` opens NP2kai's internal menu.

## Roland MT-32 / CM-32L MIDI (`munt` + MPU-PC98II)

`np2kai` connects its **MPU-PC98II** MIDI board (`$E0D0`, INT 2) directly to `czx`'s built-in background-threaded `munt` (`libmt32emu`) synthesizer via `RETRO_ENVIRONMENT_GET_MIDI_INTERFACE`.

- Place `CM32L_CONTROL.ROM` + `CM32L_PCM.ROM` (preferred) or `MT32_CONTROL.ROM` + `MT32_PCM.ROM` in `~/czx/roms/mt32/`.
- Toggle **MT-32** in `Alt + 8` (`CM-32L` / `MT-32` / `Off` / `No ROM`, persisted in `~/czx/config/czx.cfg` as `mt32 = on|off`).
- When ROMs are present and `MT-32` is `On`, MPU-PC98II is automatically enabled on boot/reset and mixed with PC9801-86 FM audio. When `Off` or ROMs are absent, MPU-PC98II stays disabled so games fall back cleanly to PC9801-86 sound.

## Configuration (`~/czx/config/np2kai.cfg`)

Defaults seeded by `czx`:

```ini
np2kai_model = PC-9801VX
np2kai_clk_base = 2.4576 MHz
np2kai_clk_mult = 4
np2kai_SNDboard = PC9801-86
np2kai_keyboard = Us
np2kai_joymode = Atari Joypad
np2kai_inputmouse = ON
np2kai_keyrepeat = OFF
np2kai_skipline = Full 255 lines
```

Other supported options include `np2kai_ExMemory`, `np2kai_usefmgen`, `np2kai_PEGC`, and `np2kai_FastMC`.
