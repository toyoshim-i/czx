# CardputerZero AppStore Release Guide

This document describes how `czx` is packaged into an ARM64 `.deb` for the
official [CardputerZero AppStore](https://github.com/CardputerZero/packages)
(`dev.cardputer.cc`).

## Store Assets & Metadata

- [app-builder.json](../app-builder.json) — Package & AppStore metadata (`share_code: CZX0`, categories `Emulators` / `Games`, permissions `external_display: true`, EN/JA locales)
- [packaging/store/icon.png](../packaging/store/icon.png) — `256×256` RGBA PNG store icon (generated by [scripts/gen_icon.py](../scripts/gen_icon.py))
- [packaging/store/screenshots/](../packaging/store/screenshots/) — `320×170` PNG store screenshots (`01-launcher.png`, `02-g800-hud.png`, `03-menu.png`)
- [packaging/store/copyright](../packaging/store/copyright) — License & upstream attribution (explicitly states no copyrighted ROMs are bundled)

## Building the `.deb`

If `dist-arm64/` already contains the ARM64 binaries, build the stripped
`.deb` package directly:

```bash
./scripts/build-deb-arm64.sh
```

Or run a full cross-compile from source (automatically invokes
`build-deb-arm64.sh` when `dpkg-deb` is available):

```bash
./scripts/build-arm64.sh
```

Output: `dist-arm64/czx_<version>_arm64.deb`

To bump the version cleanly for an update, update `"version"` in
[app-builder.json](../app-builder.json) (or pass `--version <ver>` to
`scripts/build-deb-arm64.sh`).

## Testing on Cardputer Zero

```bash
scp dist-arm64/czx_0.9.2_arm64.deb pi@<cardputer-zero-host>:/tmp/
ssh pi@<cardputer-zero-host> "sudo dpkg -i /tmp/czx_0.9.2_arm64.deb"
```

After installation, `czx` appears in APPLaunch and can also be launched from
a shell via `czx`. User ROMs and media live under `~/czx/{roms,media}/`.

## Submitting to the Store

Either submit through the CLI (`czdev`) or upload via the web developer portal:

1. **Via `czdev` (from `CardputerZero/AppBuilder`)** — run in the repo root where `app-builder.json` lives:
   ```bash
   /path/to/CardputerZero-AppBuilder/czdev login
   /path/to/CardputerZero-AppBuilder/czdev publish --deb dist-arm64/czx_0.9.2_arm64.deb
   ```
2. **Via Web Portal** — drag `dist-arm64/czx_0.9.2_arm64.deb` onto
   <https://dev.cardputer.cc> and fill in the fields matching `app-builder.json`.

> **First release policy:** Per `CardputerZero/packages` review rules, the
> very first release of a new package is reviewed manually rather than
> auto-merged. After the PR is created, post a short video (a phone recording
> is fine) showing `czx` running on a physical Cardputer Zero in the PR
> comments. Subsequent version updates auto-merge once CI passes.
